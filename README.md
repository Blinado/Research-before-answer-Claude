# Research-before-answer-Claude
THis Repository is a Claude SKill you put skill in Claude and he do fast check before giving a answer, **Research Before Answer — Claude Skill**

A powerful Claude skill designed to prioritize research, fact-checking, and accuracy before generating answers. It encourages Claude to investigate reliable sources, verify important information, cross-check facts, and avoid hallucinations or unsupported assumptions.
**Research first. Verify facts. Answer with confidence.**
